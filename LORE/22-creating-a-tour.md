Creating a Tour**

1.   After placing the signposts needed for your tour, you need to return to the Nova Initia site and navigate to the signposts page. Once there, you will see a list of all the signposts you have ever placed. Each signpost can only be used in one tour, so only signposts not currently used in a tour are available for creating your new tour.

5.   The simplest kind of tour is the "bee line". Signpost A to signpost B to signpost C, etc. While leveling up, Guides can add branches to the tour; i.e., after signpost A the tour branches to signpost A1 and to signpost B (two branches), then signpost A1 branches to signposts A2 and A3 (two more branches) and signpost B branches to signposts B1 and B2 (two more branches). There are four available positions because each signpost can branch into four directions. Please note that there cannot be interaction (looping) between the branches. Their only common link is the signpost they originated from.
